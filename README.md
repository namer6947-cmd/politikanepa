# НЭП — между рынком и властью

Интерактивная презентация экономического эксперимента 1921–1929 годов: 14 слайдов, объёмная модель экономики и интерактивные объяснения.

## Управление

- Стрелки, Page Up / Page Down и пробел — переключение слайдов.
- M — оглавление, F — полный экран.
- Кнопки, здания и ползунки управляют учебными моделями.
- «Ракурс» меняет угол обзора.

Откройте `index.html` локально или используйте GitHub Pages. Установка зависимостей не требуется.

Все изображения в сцене — авторская условная реконструкция. Числа урожая и налога являются учебными допущениями. График ножниц цен схематический, без статистического масштаба. Исторические источники перечислены в `sources.json`.
